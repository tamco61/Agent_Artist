# АХ: Агент-художник

Лабораторная работа Ахатова Тимура. Основные результаты — восемь завершённых тем: Yandex ART и SDXL Base, три раунда на тему, 48 генераций и 16 итоговых картин.

## Материалы

- [REPORT.md](REPORT.md) — краткий отчёт.
- [Галерея](gallery/index.html) — все восемь тем, переключение раундов и диалоги.
- [Agent_Artist.ipynb](Agent_Artist.ipynb) — актуальный код генерации.
- [executions/](executions/) — исполненные блокноты.
- [results/](results/) — изображения всех раундов, полные диалоги и журналы запусков.
- [collection.json](results/collection.json), [summary.json](results/summary.json) и [provenance.json](results/provenance.json) — данные новой серии и источники файлов.

Арт-директор и инженеры используют YandexGPT. Критик первых двух тем — Gemini 3.5 Flash-Lite, следующих шести — Qwen3.6 35B через Yandex API. В каждом раунде художники генерируют новые картины из текста; обмен приёмами идёт через сообщения критика и инженеров. Итог — два изображения третьего раунда.

## Локальный просмотр

Откройте `gallery/index.html` в браузере: данные галереи встроены в страницу, отдельный сервер не нужен. Изображения и ссылки на материалы работают из локальной папки проекта.

## Генерация в Kaggle

1. Импортируйте `Agent_Artist.ipynb`; включите Internet и GPU T4.
2. Добавьте Secrets `api_key` и `folder_id`, разрешите блокноту доступ.
3. Выполните установочную ячейку, затем **Run → Restart & clear cell outputs**.
4. Задайте `THEME`, оставьте `RESUME_DIR = ""` и запускайте с ячейки «Настройки».
5. Сохраните ZIP результатов и исполненный блокнот.

Yandex ART получает не больше 500 символов. SDXL использует один text2img-пайплайн с CPU offload. При продолжении запуска сохранённые изображения используются повторно.

Код обновлён после экспериментов; фактически исполненные версии сохранены в `executions/`. В репозитории оставлены восемь завершённых запусков текущей серии. Исходные загрузки, материалы прежней серии и дубли вынесены в резервную папку вне репозитория.
